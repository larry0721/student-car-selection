# Published vehicle authority artifact

The recommendation runtime loads `data/published-vehicle-intelligence/golden-set-v1.runtime.json`. This is an intentionally versioned production artifact and is not covered by the ignore rule for mutable publication repositories.

The mutable reviewed-knowledge and owner-decision repositories remain local governance inputs because they retain source-derived review state. The specific reviewed `golden-set-v1.json` publication repository is trackable as the reproducibility source; other mutable publication repositories remain ignored. `pnpm publish:golden-v1` validates the governance inputs, publishes the five-record golden set, and writes both the reviewed repository and runtime artifact. `pnpm generate:vehicle-authority-artifact` writes the runtime artifact. `pnpm verify:vehicle-authority-artifact` regenerates it in memory, compares exact bytes with the tracked artifact, and never rewrites production data.

The runtime artifact is checked in so a fresh clone and deployment use the reviewed bytes without depending on local-only repositories. Its `schemaVersion`, `artifactVersion`, resolver contract version, canonical identity contract version, publication policy versions, authority-field allowlist, explicitly non-scoreable fields, source repository identity/version, publication metadata, vehicle count, and deterministic generation fingerprint are validated before any publication is exposed to the resolver. Missing files fail the build. Malformed, stale, duplicate, non-production, non-finite, or identity-incomplete records throw during module loading and cannot partially override the legacy catalog. The `prebuild` hook runs the verification command, so drift between the reviewed repository and runtime artifact blocks production builds.

Promotion is intentionally manual and review-gated: source contributions → validation → reviewed publication → artifact generation → artifact verification → code review → tracked reviewed repository and runtime artifact → production consumption. Generation never makes unreviewed local data authoritative by itself; both changed files must pass review and enter version control together.

Rollback uses repository history: restore a prior reviewed commit containing the known-good source repository and matching runtime artifact, run verification and the regression suite, then promote that revision. Runtime rollback requires no provider access, source reconstruction, or scoring changes.

EPA fuel economy retains its canonical unit. Gasoline and conventional-hybrid `mpg` values may populate `Vehicle.mpg` after field eligibility checks. Electric `kwh_per_100_miles`, range, and retained source MPGe evidence remain in the artifact but do not populate gasoline MPG because the legacy runtime field cannot represent their semantics safely.
